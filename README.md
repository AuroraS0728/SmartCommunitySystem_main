# 智慧社区物业管理系统（毕业设计）

> **声明**：本项目仅为学生毕业设计作品，**严禁用于任何商业用途**，**尤其不得用于买卖、交易毕业设计成果**。

## 项目简介

基于 Spring Boot + Vue 3 + 微信小程序的智慧社区物业管理系统，覆盖业主、物业管理、家政/维修人员三种角色。

## 功能概览

- **业主端（小程序）**：登录、物业/停车费查询及积分支付、报修、公告、邻里互动、门禁、投诉建议
- **管理端（Web）**：房屋/业主管理、工单分配、费用账单、公告发布、访客管理、维修人员排班、角色权限、数据统计
- **维修端（小程序）**：任务接单、工单处理、验证码验证、个人中心、绩效统计

## 技术栈

- 后端：Spring Boot 3.2 + MyBatis-Plus + MySQL 8.0 + Redis + JWT
- Web前端：Vue 3 + Vite + Element Plus
- 小程序：原生框架 + Vant Weapp
- 人脸识别：SeetaFace6

## 快速开始

1. 执行 `db/schema.sql` 导入数据库
2. 修改 `backend/application.yml` 中的数据库/Redis配置，运行后端：`mvn spring-boot:run`
3. 进入 `web-admin`，执行 `npm install && npm run dev`，访问 `http://localhost:5173`
4. 用微信开发者工具打开 `weapp-owner`，配置后端 API 地址

## 注意事项

- 使用虚拟积分模拟支付（1积分=1元），未接入真实微信支付
- 人脸识别需自行配置 SeetaFace6 模型文件
- 首次运行请创建数据库并导入初始数据
