# Package Diagrams

This directory contains package-diagram source files for the Smart Community system.

Files:

- `ui-package-diagram.puml`
- `business-package-diagram.puml`
- `data-access-package-diagram.puml`
- `config-management-package-diagram.puml`
- `exception-handling-package-diagram.puml`

Recommended usage:

1. Open these files with a PlantUML plugin in IntelliJ or VS Code.
2. Export PNG or SVG.
3. If you need Visio figures, use the exported SVG/PNG as a tracing reference and redraw with consistent package blocks.

Notes:

- The diagrams are based on the current project structure under `backend`, `web-admin`, and `weapp-owner`.
- The package names reflect the actual source layout rather than generic textbook placeholders.
